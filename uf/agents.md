# AGENTS.md

Демонстрационная конфигурация «Демонстрационное приложение» (`ДемонстрационноеПриложение`, версия **1.0.41.3**, поставщик Фирма «1С»): торговля и склад (заказы, приход/расход товаров, оплаты, взаиморасчеты), почта, мобильный обмен, система взаимодействия, бот.

Параметры конфигурации: управляемое приложение, язык скрипта русский, язык по умолчанию `Русский`, режим совместимости **8.3.27**, режим совместимости расширений **8.5.1**, интерфейс `Taxi`, управляемые блокировки, модальность и синхронные вызовы не используются (`DontUse`) — пиши асинхронный код (`Асинх`/`Ждать`, `Оповещение`). Формат выгрузки `version="2.21"`. Платформа на машине: `C:\Program Files\1cv8\8.5.1.1529\bin`.

Это иерархическая выгрузка конфигуратора в файлы (не EDT).

## Обязательные правила

1. **Информационная база.** Конфигурация связана с файловой ИБ `File="C:\Users\psi\Downloads\AICourse\DBIS06_UF"`. Пользователь `Администратор`, пароль пустой. Пример строки запуска: `1cv8.exe DESIGNER /F"C:\Users\psi\Downloads\AICourse\DBIS06_UF" /N"Администратор" /P"" /DisableStartupDialogs`.
2. **Вся разработка ведется в новых расширениях.** Под каждую доработку создавай новое расширение (скилл `cfe-init`), объекты основной конфигурации заимствуй (`cfe-borrow`), методы перехватывай (`cfe-patch-method`). После правок проверяй расширение (`cfe-validate`).
3. **Расширения складываем в каталог `Extensions`:** `Extensions/<ИмяРасширения>/Configuration.xml` и объекты рядом с ним. Собственные объекты расширения называй с префиксом из `NamePrefix` расширения.
4. **В основной базе ничего не меняем.** Не правь файлы в `Config/`, не загружай в ИБ основную конфигурацию (`/LoadCfg`, `/LoadConfigFromFiles` без `-Extension`), не выполняй `/UpdateDBCfg` для основной конфигурации, не снимай объекты с поддержки. В ИБ допустимо загружать и применять только расширения (`-Extension <Имя>`).
5. **В наименованиях метаданных используем «е» вместо «ё»:** имена и синонимы объектов, реквизитов, форм, команд, процедур и переменных (`Счет`, а не `Счёт`; `Расчеты`, а не `Расчёты`).
6. **Тестирование доработок — Vanessa Automation из `C:\Users\psi\Vanessa`** (см. раздел ниже).

## Куда смотреть

- `Config/Configuration.xml` — свойства и состав конфигурации (`ChildObjects`).
- `Config/ConfigDumpInfo.xml` — индекс выгрузки, вручную не править.
- `Config/Ext/` — модули приложения и сеанса (`ManagedApplicationModule.bsl`, `SessionModule.bsl`), командный интерфейс, начальная страница.
- `Extensions/` — расширения проекта (см. раздел «Расширения проекта»).

Код лежит в `*.bsl` рядом с XML объекта:

```
Config/Catalogs/Товары.xml
Config/Catalogs/Товары/Ext/ObjectModule.bsl
Config/Catalogs/Товары/Ext/ManagerModule.bsl
Config/Catalogs/Товары/Forms/ФормаЭлемента/Ext/Form.xml
Config/Catalogs/Товары/Forms/ФормаЭлемента/Ext/Form/Module.bsl
Config/CommonModules/<Имя>/Ext/Module.bsl
```

Для изучения структуры используй скиллы `cf-info`, `meta-info`, `form-info`, `skd-info`, `role-info`, `subsystem-info` вместо чтения XML целиком.

## Типовой цикл доработки

1. Изучить затрагиваемые объекты (`meta-info`, `form-info`).
2. Создать расширение в `Extensions/<Имя>` (`cfe-init`), заимствовать объекты (`cfe-borrow`), написать код/перехватчики (`cfe-patch-method`).
3. Проверить (`cfe-validate`), загрузить расширение в ИБ (`db-load-xml` с `-Extension`, затем `db-update` с `-Extension`, или одной командой `tools\ext-load.ps1 -Base UF -Name <Имя>`).
4. Написать `.feature` и прогнать через `va.ps1`; приложить путь к отчету.

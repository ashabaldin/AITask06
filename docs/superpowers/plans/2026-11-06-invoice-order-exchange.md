# Обмен «Счет БСП → Заказ УФ» через файлы — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ручная выгрузка `_ДемоСчетНаОплатуПокупателю` из БСП в JSON-файл и ручная загрузка его в `Заказ` УФ без дублей, с сопоставлением справочников через регистр соответствий.

**Architecture:** Два новых расширения. БСП `ОбменСчетами` — модуль формирования JSON + обработка с полем «Файл». УФ `ЗагрузкаСчетовБСП` — регистр соответствий, модуль сопоставления, модуль загрузки, обработка с полем «Файл» и протоколом. Файл пишется/читается на клиенте (`ТекстовыйДокумент.ЗаписатьАсинх/ПрочитатьАсинх`) по пути из поля формы — это позволяет Vanessa задать путь без файловых диалогов.

**Tech Stack:** 1С:Предприятие 8.5.1.1529, расширения в XML-выгрузке 2.21, навыки cc-1c-skills (`cfe-init`, `meta-compile`, `form-compile`, `cfe-validate`, `db-load-xml`, `db-update`), Vanessa Automation 1.2.043.42 (`C:\Users\psi\Vanessa\va.ps1`).

**Spec:** `docs/superpowers/specs/2026-11-06-invoice-order-exchange-design.md`

## Global Constraints

- Основные конфигурации (`bsp/Config`, `uf/Config`) и существующие модули не меняем; в ИБ грузим только `-Extension <Имя>`.
- Расширения: `bsp/Extensions/ОбменСчетами` (NamePrefix `осч_`), `uf/Extensions/ЗагрузкаСчетовБСП` (NamePrefix `зсб_`), назначение `AddOn`, `-ConfigPath Config`.
- После создания БСП-расширения добавить его в `bsp/.v8-project.json` → `databases[0].extensions`.
- УФ: только асинхронный клиентский код (`Асинх`/`Ждать`), без модулей БСП. БСП: совместимость 8.3.14.
- «е» вместо «ё» в именах, синонимах, комментариях.
- Формат файла: `{"format":"bsp-invoices","version":1,...}` — ровно как в спеке.
- Заказы только `Записать(РежимЗаписиДокумента.Запись)`, не проводить.
- Внешние источники — ссылкой в комментарии рядом с кодом.
- Проект не под git: шаги «commit» заменены на выгрузку/валидацию расширения.
- Тестовые файлы обмена — в `C:\Users\psi\aiwsis06\exchange\` (каталог создать).

## Review Focus

1. Файл не того формата/версии или битый JSON → загрузка ничего не меняет, протокол «Неверный формат файла». (Task 4)
2. Счет без строк товаров → заказ создается/обновляется с пустой ТЧ, не падает. (Task 4)
3. Два товара УФ с одинаковым наименованием → автоподбор не выбирает случайный, протокол «неоднозначно». (Task 3)
4. Повторная загрузка того же файла → число заказов не меняется, `Склад`/`СостояниеЗаказа` не перетираются. (Task 4, 6)
5. Один несопоставленный товар → пропускается только этот счет, остальные грузятся (транзакция на счет). (Task 4, 6)
